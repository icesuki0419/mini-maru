## 2026-11-20 문의 2번 수정
- 프롬프트 : 자기소개서 글자 수 버그를 고치는 방법 질문
- AI의 답 : 줄바꿈을 2자로 세는 함수를 만들고, 글자 수 표시와 검사 두 곳에 적용하는 코드를 제안
- 내가 확인한 것
  - 같은 테스트 글로 수정 전과 수정 후를 직접 비교함
  - 8자를 지워 1000자로 맞춘 뒤 실제 제출이 201로 성공하는 것까지 확인함
  - mock에 같은 함수가 있지만 가져다 쓰지 않은 이유를 이해함 : `src/mocks/`는 백엔드 서버로 간주하므로 프론트는 명세를 보고 직접 구현해야 함
- 배운 점
  - `.length`는 줄바꿈을 1자로 세서 명세처럼 2자로 세려면 `\r\n`으로 바꾼 뒤 길이를 세야 함
  - zod의 `.max()`는 `.length` 기준이라 직접 정한 규칙으로 검사하려면 `.refine()`을 써야 함
